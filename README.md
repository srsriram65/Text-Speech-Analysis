# Application 1 - Text Preprocessing

## Aim
To preprocess text using Python by converting text to lowercase, removing punctuation, and removing stop words.

## Description
Text preprocessing is an important step in Text Analysis and Natural Language Processing (NLP).

This application performs:
1. Lowercase conversion
2. Punctuation removal
3. Tokenization
4. Stop-word removal

## Input
I am learning Text and Speech Analysis.

## Output
['learning', 'text', 'speech', 'analysis']

## Technologies Used
- Python
- Google Colab

## Application
This program prepares raw text for further Natural Language Processing tasks.
